## False positives ruled out
- The first superseding-uuid runs used two mock ports. I confirmed this with a debug print (not committed), then re-ran on a single origin.
- A single-dependency project can't be restored to PyPI (`no sibling registry package shows the registry`). That's documented; use a sibling dependency.
- `markupsafe` import failing after a symlink-mode rollback: my loop had deleted the uv cache the venv links into.
