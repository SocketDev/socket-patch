## False positives ruled out
- Hosted rollback refused when a sibling uses an explicit `[[tool.uv.index]]` (for example the PyTorch-index pattern: "several registries" / "not PyPI"). CLI_CONTRACT lists this refusal ("other registry packages name … several, or one other than PyPI's simple index"). It's a real usability gap, because an explicit index only serves pinned packages, so the patched package's registry is derivable. But it's documented, so I didn't file it. A maintainer may want to narrow it.
- `repair` → `download_failed` in agent mode: my mock serves no diff archive (harness).
- `vex --json` → `json_requires_output`: documented (use `--output`).
