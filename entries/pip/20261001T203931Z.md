## False positives ruled out

- Hosted `rollback` "Manifest not found": my mock's artifact URL lacked the `/patch/pypi/<name>/<ver>/<tok>/<uuid>/` path, so this was a mock artifact.
- The `-r` include hash-mode gap in hosted (root-only `requires_hashes`): pip accepts the fragment hash in hash mode, so it's not a bug.
- The vendored bare path resolving against the CWD: documented ("run from the project root", CLI_CONTRACT.md).
- `six==1.16.0 \` + next line: a bad fixture on my side (an invalid requirement).
- `uv pip install --require-hashes` failing: the unhashed bystander makes that file invalid in that mode regardless.
