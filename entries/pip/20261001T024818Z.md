## False positives ruled out

- Vendored `vex` attesting while a plain venv keeps upstream bytes is documented (the committed artifact is the basis; `vendored_tree_out_of_sync` warns). It isn't a bug by itself; only the missing warning in the system-site case is (#409).
- Rollback lowercasing `Six` and collapsing spaces before `# comment` only changes the restored hosted line; pip reads it the same way. Not filed.
- `vex -o` is `--org`, not `--output`. That was my mistake, not a CLI bug.
- The `six == 1.16.0` (spaces) lock-only miss is still the known design choice. Not filed.
