Scan exits 0 `redirected: 1`, but uv obeys the source: with url / path sources a fresh env is unpatched, and with a git source every install fails with "conflicting URLs". Docs say source tables are refused. https://github.com/SocketDev/socket-patch/issues/673
- #674: an H→V takeover with two or more patches reverts the hosted pins one at a time. The first package's vendored ledger snapshots the hosted-owned `allow-direct-references = true`, so rollback / remove leave it (and empty `[tool]` / `[tool.hatch]` headers) behind. That disables Hatchling's direct-reference guard (verified with `hatch build`). https://github.com/SocketDev/socket-patch/issues/674
