## Ruled out / not filed
- Vendored scan failing `package_not_installed` without `VIRTUAL_ENV`: the mock has no vendoring-service endpoints, so `auto` fell back to a local build. With the real service it downloads. This is a mock artifact, apart from the discovery gap already in #335.
- Hatch's internal envs (`hatch-test`, `hatch-build`, `hatch-static-analysis`, `hatch-uv`) default to `installer = "uv"`, and the vendored uv refusal doesn't consider them. But uv 0.12 **does** enforce `#sha256=` on local wheels, so there's no integrity gap. docs/testing/hatch.md's "uv ignores hash fragments for local wheels" looks outdated; the refusal is only over-conservative.
- `rollback` on a project where nothing was written exits 2 `Manifest not found`: benign.
