## False positives ruled out

- `vex --json` without `-O` gives `json_requires_output`; `-o` is `--org`. These are usage errors on my side.
- Standalone `vex` reporting `no_applicable_patches` without `--api-url` / `--org` happens because it can't fetch the vulnerability metadata from the mock. It's a harness artifact.
- Poetry 1.x's `boolean_normalizer` is case-sensitive (`"True"` is false), while 2.x lowercases. That's the same theoretical class as the existing `yes` / `on` note (it only diverges with a stray `.venv`). Not filed.
- Release 3.3.0 patched neither copy in the #671 layout (an older discovery model), so it isn't a "good" baseline.
