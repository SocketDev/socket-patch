## False positives ruled out

- `;` in the project path breaks Poetry 1.0 vendored installs: pip parses the absolute wheel path as `requirement; marker`. Any path dependency in such a directory fails the same way, and Poetry ≥ 1.2 (installer, no pip) is fine.
- `list --json` "empty": my parser read `patches`; the envelope uses `events[].action = discovered`. `list` is correct.
- Hosted rollback refusing for multi-pylock exports: documented `hosted_restore_refused` (no sibling registry package).
