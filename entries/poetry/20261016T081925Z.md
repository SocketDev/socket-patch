## False positives ruled out

- Vendored wiring `pylock.toml` instead of `poetry.lock` when both pin the package: `PYPI_TOOL_LOCKS` documents that standalone PEP 751 locks rank between uv and Poetry when they pin the package (`crates/socket-patch-core/src/formats/governing_locks.rs:110`). The run warns `pypi_multiple_lockfiles`, and `vendor --check` flags the contest. Hosted rewrites both files, so the two modes differ on purpose.
- Rolled-back `pylock.toml` URLs pointing at `127.0.0.1/fph`: my PyPI JSON forwarder rewrites `files.pythonhosted.org`. That's a harness artifact. The dropped `# requires-python` comment and the millisecond `upload-time` fall under "no guarantee of the original byte layout".
