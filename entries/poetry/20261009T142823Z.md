## False positives ruled out

- Hosted rollback isn't byte-identical for hand-edited shapes (inline / tab / empty / wheel-only `files`, quoted `[metadata.files]` keys, `six=[`). It re-renders Poetry's canonical shape from PyPI, which docs/testing/poetry-compatibility.md documents ("no … guarantee of the original byte layout").
- The `source = "pypi"` failure isn't a mock artifact: the same mock serves the plain cells, which install fine on every version, and `vendor --revert` alone restores the install.

## Docs drift (not filed)

- docs/testing/poetry-compatibility.md line 24 still says LF 2.x locks keep the multi-line `files` and that CRLF / legacy locks get "a single-line inline array". Since #1185, CRLF vendored and hosted locks get the multi-line layout too (checked on 2.5.1 CRLF).
