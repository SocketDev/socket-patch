## False positives ruled out
- With the mock on 127.0.0.1, hosted pins only count as hosted wiring if `SOCKET_PATCH_SERVER_URL` / `--patch-server-url` points at the mock. Without it, `vex` reports `vendor_unwired` or "no hosted patch references". That's documented `--patch-server-url` behaviour and a harness artifact.
- Vendored mode now always downloads prebuilt artifacts (`--vendor-source service`, local building is gone). `vendor --offline` with only a staged manifest fails with `vendor_service_offline_conflict`. Point `SOCKET_VENDOR_URL` at the mock instead.
