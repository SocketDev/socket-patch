## False positives ruled out
- A workspace member that lives under `vendor/`, `build/`, `dist/`, `tmp/`, `temp/`, `coverage/` or a hidden dir (e.g. `.github/actions/*`) is never crawled in agent mode, so its non-hoisted copy isn't patched. That's the documented walk (docs/ecosystems.md "npm: which node_modules trees are crawled"), so I didn't file it. Declared yarn `workspaces` globs aren't consulted, and whether they should be is a design question.
