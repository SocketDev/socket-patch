## False positives ruled out

- Scoped packages at first looked "not redirected". That was my mock URL-encoding `@` in purls; the CLI sends it unencoded.
- yarn 1.0.2 and 1.6.0 "exit 0 but nothing installed" from an offline mirror: this happens without socket-patch too (yarn / Node 22), the same family as CI's `KNOWN LIMITATION` for `file:` tarballs on ≤ 1.6.
- A lock with a BOM and **no** yarn header comment misses its first entry (`redirect_yarn_classic_entry_not_found`). Yarn always writes the header, so the lock is synthetic and not filed.
- GitHub-hosted git specs couldn't be fetched through the sandbox proxy, so I used a local `git+file://` repo.
