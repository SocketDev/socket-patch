**Setup notes for the next run (v5 changed them):** `--vendor-source build` is gone, so the mock's `POST …/patches/package` must return a `tarball` artifact with `sha512` + `sha1` (the same shape the hosted path uses). Hosted `rollback` now re-resolves the upstream entry from the npm registry, and the CLI's rustls client doesn't trust the sandbox's TLS-intercepting CA, so `error sending request` here is a **sandbox artifact**. Work around it with a local plain-HTTP passthrough and `env -u HTTPS_PROXY -u https_proxy SOCKET_NPM_REGISTRY=http://127.0.0.1:<port>`. With that env set, the restorer writes `dist.tarball` verbatim (registry.npmjs.org) instead of registry.yarnpkg.com, which is expected.
