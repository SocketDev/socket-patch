## Ruled out / not filed
- Mixed-ending hosted rollback: scan only normalizes the edited `[[package]]` unit, but hosted rollback rewrites the whole file to LF. Vendored rollback is byte-exact, and so is a pure-CRLF hosted rollback. PDM never writes a mixed lock, and the result is semantically identical (`lock --check` passes), so it's cosmetic. It does contradict pdm-compatibility.md's "preserves line endings". Recorded as a known non-bug.
- BOM: PDM's own TOML reader rejects it.
- Harness pitfalls (not bugs): `pdm venv create` / `pdm use` in a fresh dir can reuse another project's interpreter in `.pdm-python`; out-of-tree venvs are shared across copies of a project dir; hosted refs on a mock origin need `SOCKET_PATCH_SERVER_URL`; vendored grants need `integrity.sha512` as SRI (`sha512-<b64>`).
