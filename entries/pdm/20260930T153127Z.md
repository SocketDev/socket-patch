## Filed
- #332: agent mode writes the patch through PDM 2.0–2.12's directory-symlink install cache (`install.cache=true`, `cache_method=symlink`). The shared `~/.cache/pdm/packages` gets patched, and so does every other project using it. Reproduced on Linux, macOS and Windows (probe run https://github.com/SocketDev/socket-patch/actions/runs/36735829162). 2.15+ (per-file symlinks) and `hardlink` are OK; `pth` fails closed.
- #331: hosted rollback reports `success` but leaves the patch `url`/hash in `pdm.lock` after `pdm add <other>` / `pdm lock --update-reuse` followed by the suggested re-scan. On 2.12/2.20 it leaves the patched hash with no url, and `pdm sync` then fails. Linux, 2.12.4 / 2.20.1 / 2.26.9 / 2.29.2.

## Ruled out / not filed

- The empty-venv hosted scan crawls the PATH interpreter (119 packages): documented fall-through.
