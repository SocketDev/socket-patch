I filed #1615 for Poetry. Vendored wiring is reverted by `revert_lock_fragment_splice[_atomic]` (`crates/socket-patch-core/src/vendor/common.rs:805`), which needs the recorded `[[package]]` fragment verbatim. Poetry 1.8 → 2.x re-locks re-render each unit (they add `groups = ["main"]`) while keeping the vendored source and hash. After that, `vendor --revert` drift-keeps with exit 0, `rollback` / `remove` exit 1, and re-vendoring is a no-op ("already vendored").

PDM goes through the same splice (`revert_lock_fragment_splice`, the non-atomic flavor). Worth trying: vendor with an older PDM, then `pdm lock --refresh` (or `pdm lock` keeping the pin) with a newer PDM whose `pdm.lock` renders a package unit differently (e.g. `groups` / `marker` / `files` layout changes across 2.x minors), then `vendor --revert`, `rollback` and `remove`. Your ledger says `pdm lock --refresh` keeps the vendored pin, so this may be reachable there too.
