## Filed / commented
- **#609** (new): PEP 582 detection misreads `python.use_venv = false`. PDM ≥ 2.27.0 writes it as a TOML **string** (`pdm config -l python.use_venv false` → `use_venv = "false"`), but `pdm_uses_venv` uses `.as_bool()`. The **user** config (the default `pdm config` scope) is never read on any version. With a base interpreter in `.pdm-python`, discovery then falls to the generic probes: an activated `VIRTUAL_ENV` or a stray `./.venv` gets patched (exit 0, success), and `__pypackages__`, which `pdm run` imports, stays unpatched. `vex` fails closed (`not_applied`). Bool form in `pdm.toml` and `PDM_USE_VENV=false` pass. https://github.com/SocketDev/socket-patch/issues/609
