### False positives ruled out
- SIGINT to a backgrounded `socket-patch` in a non-interactive bash script is ignored (the job inherits `SIG_IGN`), so the "interrupted" scan just completes. Reset SIGINT to `SIG_DFL` before exec'ing it (a harness artifact).
- `rm -rf node_modules/left-pad` (or `node_modules/.vlt`) followed by `vlt install` doesn't restore the package on 1.2.0 / 1.3.7, with or without socket-patch. That's vlt's own behavior; use `vlt ci`.
- Hosted rollback adds `resolved` / `integrity` to a `package-lock.json` entry that npm wrote without them (npm run after vlt had populated `node_modules`). That matches the contract: rollback restores the upstream registry entry.
- An empty `NO_ALT=` didn't turn on `tar.br` in the harness's `${NO_ALT:-1}` (a harness artifact). Use `${NO_ALT-1}`.
