## False positives ruled out
- A global `~/.bundle/config` `mirror.all` isn't inspected by the merged #681 guard. That's documented ("user-global config … not inspected").
- Bundler 4.0.22's `Settings#path` only applies `deployment` → `vendor/bundle` when no tier sets a path, so a global `path.system` beats a local `deployment`, and the crawler agrees. `disable_shared_gems: false` (system gems in Bundler, ignored by the crawler) is never written by Bundler itself, so it's contrived and not filed.
- An unconstrained `gem "colorize"` cell first looked like a separate "frozen install" bug. It's #1055 (the lock resolved 1.1.0, the shared home had 0.8.1).
