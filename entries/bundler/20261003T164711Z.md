## False positives ruled out
- ZenTest "rollback fails / frozen install 16": a harness error. `~> 4.12` resolved 4.12.2 while the mock served a 4.12.1 patch.
- `get <uuid> --mode hosted` for a version the lock doesn't hold (4.12.1 vs a locked 4.12.2) pins and downgrades the gem, adds a second CHECKSUMS line, and leaves a mixed pair that `rollback` / `remove` can't find (`Manifest not found`) until the prescribed unfrozen `bundle install` has run (after that, rollback works). The uuid path is documented as exempt from installed narrowing, so it's not filed. Recorded under Known non-bugs.
- "Cannot write a changed lockfile while frozen." (exit 0) on Bundler 4 with a CRLF lock: Bundler prints it for the pristine CRLF lock too.
- The in-place hosted rewrite of a CRLF manifest writes its `source … do` block with LF endings (mixed endings). Bundler, frozen installs and rollback all accept it, so it's cosmetic.
