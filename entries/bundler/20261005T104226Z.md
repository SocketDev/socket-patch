## False positives ruled out
- `get --json` after a failed apply shows `failed: 0`. `failed` counts downloads only; status `partial_failure` + exit 1 carry the failure (by design, not specific to gems). Added to Known non-bugs.
- `pkill -f mock2.py` inside a command line that contains `mock2.py` killed my own shell (exit 144), as the ledger already warns.
- Bundler 2.4.22 wasn't preinstalled in this container (`gem install bundler -v 2.4.22`); the harness gate catches it.
- `git push --delete` for the probe branch hung up again, so the branch is left behind (push-triggered workflow only).
