## False positives ruled out
- `BUNDLE_PATH: ".gems" # c` (quoted value + comment) and a quoted value with trailing spaces: Bundler's own loader keeps the quotes and breaks too, so it's not socket-patch's divergence.
- `inspect`-escaped values (Windows backslashes, `\u…`): neither Bundler nor socket-patch unescapes them, so they agree.
- setup-ruby `bundler-cache` with a matrix `BUNDLE_GEMFILE`: it records an absolute `$PWD/vendor/bundle`, which the default probe finds. Only relative paths hit #952.
