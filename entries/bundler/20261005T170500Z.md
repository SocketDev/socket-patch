## False positives ruled out
- **Bundler 4.0.19+ fails frozen installs on any CRLF lock**, pristine included (exit 16; 4.0.17 only warned). That's Bundler's change (rubygems #9750), not socket-patch. The Known non-bugs entry is updated.
- Bundler 4.0.18+ `cooldown`: versions without `created_at` and locked versions are never filtered, so a hosted pin is unaffected (read from the 4.0.22 source).
- The standalone stale-install remedy says `bundle install` rather than `bundle install --standalone`. The failure that follows is loud (`LoadError`), so it's a wording nit and not filed.
- An earlier standalone remedy test installed the patched colorize into system gems, which made a later system-gems cell look "PATCHED". I uninstalled it and re-ran. Agent cells on system gems patch the real system copy, so clean up after them.
- Windows probe harness: MSYS converted `icacls /deny` into a path (run 1), and my writability check appended to the gem file (run 2). Both were fixed in run 3.
