## False positives ruled out
- `scan` without `--mode` is hosted in v5. My first agent probe hit "Failed to resolve patch references" because the agent-only mock has no `/patches/package` endpoint. Pass `--mode agent` explicitly.
- `cargo test … -- --ignored --include-ignored` prints nothing, because the flags conflict. Use `--include-ignored` alone.
- An agent probe on a system-gems project patches the shared `/opt/rbenv/…/colorize-0.8.1`. My mock serves no blobs, so `rollback` can't restore it; restore with `gem pristine colorize -v 0.8.1`.
