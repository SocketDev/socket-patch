**Setup (new, reusable):** a Python mock (`mock2.py` pattern) serving the patches API (batch / by-package / package / view with `blobContent`) plus one patch-registry compact index per uuid, with **real rubygems.org as the upstream**. It serves real gems rebuilt with a marker line (`gem unpack` → append `SOCKET_PATCHED_<NAME> = true` → `gem spec --ruby` → `gem build`). For vendored takeovers, the run-16 scratch test binary (`prebuilt_common::Server::project_with_env(<staging root>)`) serves artifacts, and the Python mock proxies every non-`/v0`, non-`/patch-registry` GET to it. That way `--patch-server-url <mock>` makes the hosted wiring recognizable **and** routes artifact downloads correctly. Export `SOCKET_VENDOR_URL=<prebuilt uri>` too, or `/patches/package` hits the API mock (`tarball artifact has no sha512 integrity`). The scratch test file was deleted afterwards.

- `pgrep`/`ps | grep` patterns that also appear later in the same command line (e.g. a `rm …zz_scratch…` in the same shell) kill the agent's shell (exit 144) again. Keep kill commands in their own Bash call.
