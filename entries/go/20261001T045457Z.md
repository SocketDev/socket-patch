## False positives ruled out
- `go mod verify` "dir has been modified" after a byte-exact rollback: a fixture artifact. `zip -r` adds directory entries, which changes the zip h1 hash. Rebuilt the fixture with `zip -D`, and verify passes on a pristine cache and after rollback.
- 1.25.1 "before: PATCHED": a fixture artifact. As non-root, `rm -rf` can't delete the read-only module cache, so the previous run's patched cache survived. Fixed with `chmod -R u+w` first.
- Project (hosted default) `scan` exit 1 "failed to resolve patch references": my mock doesn't implement the hosted reference endpoint. Not a bug.
