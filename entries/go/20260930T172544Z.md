## Cells

- **Agent `apply` + rollback, odd module paths and versions (Linux):** pass for uppercase path (`example.com/Azure/Upstream`), `/v2` module, pseudo-version, uppercase pre-release, `gopkg.in/x.v3`. Rollback restores go.mod byte-exact.
- **Agent, CRLF go.mod:** pass (CRLF kept, byte-exact rollback).
- **Agent, idempotent re-apply + `go mod tidy`:** pass (both no-ops).
- **Agent, user version-less `replace M => ../fork`:** loud refusal (`user-authored replace … refusing to overwrite`). OK.
- **Agent/vendored with a committed `vendor/` (go mod vendor):** **fail → #343**. Exit 0, but the build breaks with "inconsistent vendoring", `apply --check` says in sync, and VEX attests. Covered Linux 1.16/1.21/1.24/1.26 and macOS 1.24/1.26.
- **`go env -w` settings (GOENV file):** **fail → #344**. GOPRIVATE leaks the module path to proxy.golang.org, a GOPROXY mirror is bypassed, and GOMODCACHE is not found. Covered all 8 probe cells (Linux, macOS, Windows).
- **Windows agent `apply` / vendored `vendor`:** **fail → #346**. `Access is denied (os error 5)` because of the read-only attribute copied from the module cache. Covered windows-latest and windows-2022 × go 1.16/1.21/1.26, main and 4.0.0. Clearing R makes it pass.
- **Agent upgrade drift (`go get M@v1.0.1` after apply):** `apply --check` flags it (exit 1), **but `vex` still attests `not_affected` for `M@v1.0.0` (exit 0)**. Vendored mode correctly omits it (`vendor_unwired`). Reproduced 3× on main plus 4.0.0. **Not filed yet (3-issue cap)**; it's backlog item 1, and the draft is below.
- **go.work root that is not itself a module (`use ./svc`), `apply` at the root:** exit 1, "matched no installed package". Loud; see backlog. From the member directory: pass (both the member build and the workspace build are PATCHED).
- **Vendored `repair` after deleting `.socket/vendor/golang`:** pass (rebuilt offline). Agent `repair` doesn't rebuild `.socket/go-patches` (repair's help limits it to vendored artifacts, so that's not a bug). A re-`apply` heals it.
- **`remove`:** pass (go.mod restored).
