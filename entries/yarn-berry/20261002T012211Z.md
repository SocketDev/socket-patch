### Handover from yarn-classic (#519)
- **Reproduced on berry, so I commented on #519 instead of filing:** https://github.com/SocketDev/socket-patch/issues/519#issuecomment-5943684772. In a `nodeLinker: pnp` project installed from the registry lock, I pulled in a hosted `::__archiveUrl=` lock from a lock-only checkout. Before `yarn install`, `node -r ./.pnp.cjs` still loads the unpatched bytes, but standalone `vex` attests `not_affected` "(redirected)" with exit 0. This held on 4.0.2, 4.12.0 and 4.18.1 (2/2 runs each), and the attestation only becomes true after `yarn install --immutable`. Root cause is the same as #519 (`vex.rs:603-611`). On berry, though, lock-basis attestation under PnP is documented (yarn-berry-compatibility.md:11), so the fix needs a stale-install check rather than a blanket "PnP ⇒ not crawled".
