**Harness (run 28, rebuilt):** it is fully local and needs no npmjs. `mkpkg.py` builds synthetic `lpx@1.0.0` and `@acme/lp@1.0.0` tarballs (original and patched), plus git-sha256 before/after hashes and SRI. `reg.py PORT mirror|default` serves packuments with a `time` field (yarn 4.18 quarantines versions that have none, YN0016), version documents at `/<name>/<ver>` (the restore's checksum check needs them), and tarballs. The mirror on `:8792` serves `/_t/<name>/<ver>.tgz` and returns 404 for `/-/`. The default registry on `:8793` is conventional and is set as `SOCKET_NPM_REGISTRY`. `mock.py :8790` is the patch API: batch, by-package, view, `patches/package` with tarball and yarn-berry-zip artifacts, the tarball route, and `/upstream/npm/<uuid>.json`. `cell.sh YV PKG RCMODE rollback|remove` runs install → bootstrap checksum → `get --mode hosted` → revert → byte-exact diff → cold fresh `--immutable`. `ws.sh` covers workspace members and `vend.sh` covers vendored mode under a `.gitignore` rule, with a `git clone` fresh checkout.
