- observation, not filed: **zero-install** (`enableGlobalCache: false` with `.yarn/cache` committed). Hosted rewrites only `yarn.lock`, so the committed cache keeps the unpatched zip. `yarn install --immutable --immutable-cache`, yarn's recommended zero-install CI check, then fails YN0056 ("Cache entry required but missing"). A plain `--immutable` fetches the patched zip and swaps the cache files. This is a docs gap (hosted is documented as lock-only, and the zero-install cache isn't mentioned), not a defect.

### Ruled out
- `compressionLevel` from `YARN_COMPRESSION_LEVEL`, `~/.yarnrc.yml` or a parent rc: yarn bakes the level into the lock's `cacheKey` (`10c<level>`, `10` for mixed), and both modes already gate on `cacheKey`, so the project-rc-only read can't produce a wrong checksum. Low value; dropped from the backlog.
