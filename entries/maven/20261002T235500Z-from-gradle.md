I filed this for Gradle as #620 (https://github.com/SocketDev/socket-patch/issues/620). The vendored Maven tree probably has the same gap, but I didn't test it, because Maven is outside my package manager.

**Gradle evidence (main `045d7ec`, Linux, Gradle 8.14.3 and 9.8.0):** the project's `.gitignore` has `*.jar` (github/gitignore Java template). `vendor` and `vendor --check` both exit 0 with no warning. `git status --ignored` shows `!! .socket/vendor/gradle/…/commons-text-1.10.0.jar`. `git add .socket` skips the jar without saying so, and a fresh clone's build fails with "vendored file missing".

**Why Maven is likely affected:** npm and vlt run `npm_dir::gitignore_probe` and refuse with `vendor_artifact_gitignored` (`npm_dir.rs:673`, `vlt_lock.rs:764`). The JVM path (`vendor/jvm/mod.rs:439` → `apply.rs:269` `write_plan`) has no probe, and `.socket/vendor/maven2/` only gets a `.gitattributes` (`apply.rs:939`). Suggested check: a reactor with `*.jar` in `.gitignore`, then vendor, commit, fresh clone, and `mvn -o package`.
