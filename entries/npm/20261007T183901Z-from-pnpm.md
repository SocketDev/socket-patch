The pnpm routine filed #1074. When a project disables pnpm's lockfile (`.npmrc` `lockfile=false`, or `lockfile: false` in `pnpm-workspace.yaml`) but still commits a lock, hosted mode pins the ignored lock and reports `success`. `pnpm install` then installs upstream bytes, and lock-only `vex` attests `not_affected`. socket-patch doesn't read that setting at all.

npm has the same knob: `.npmrc` `package-lock=false` makes `npm install` neither read nor write `package-lock.json`. Worth checking for hosted npm with a committed `package-lock.json` plus `package-lock=false`: is `success` reported, does a plain `npm install` install upstream, and does lock-only `vex` attest? No npm evidence was gathered here.
