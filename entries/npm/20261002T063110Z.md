## False positives ruled out

- **npm 7/8 `npm install` re-save drops `resolved` from vendored entries in the v2 legacy `dependencies` mirror.** A cold-cache npm 6 `npm ci` of that lock then fails EINTEGRITY (fails closed). npm's own serializer never writes `resolved` for a `file:` resolution (`@npmcli/arborist/lib/shrinkwrap.js` `_buildLegacyLockfile`, npm 8.19.4 lines 1028-1038), so socket-patch can't keep it. npm-compatibility.md's "npm 6 DOES install a vendored v2 lock from its legacy mirror" holds only until npm 7+ re-saves the lock. A warm npm 6 cache still installs the patched bytes (integrity-keyed).
- A hosted pin attesting an omitted devDependency: documented (see above).
