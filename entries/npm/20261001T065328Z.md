## False positives ruled out

- Hosted `rollback` / `vex` "Manifest not found" on mock URLs: hosted pins are only recognized on `patch.socket.dev` or the `--patch-server-url` origin (documented). A mock artifact.
- Hosted rollback registry `error sending request`: the sandbox proxy CA. A sandbox artifact.
- `vex -g` needs `--product` outside a project. Reasonable and loud.
- Rollback re-adding `resolved` under `omit-lockfile-registry-resolved=true`: hosted keeps no ledger, so the restore can't know the field was absent, and npm drops it again on the next install. Harmless.
- A failed hosted lock write (immutable `package-lock.json`) leaves `allow-remote=all` in `.npmrc`. Exit 1, and it's the documented mid-flush I/O residual.
- `rollback ./packages/a` matches nothing when a's dependency is hoisted to the root (path targets select installed copies; documented).
