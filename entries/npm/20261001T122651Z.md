## Cells

- **Hosted + `.npmrc` `registry=` mirror** (local rewriting mirror), npm 10 and npm 12: pass. Scan, fresh `npm ci` (patched), rollback, then `npm ci` all work. Rollback restores `resolved` to `registry.npmjs.org` rather than the mirror. That's documented ("default upstream registry entry", `SOCKET_NPM_REGISTRY`), and npm's `replace-registry-host` keeps `npm ci` working. `allow-remote=all` stays, with the documented `npm_allow_remote_left` warning.
- **`.npmrc` variants for allow-remote:** no trailing newline, CRLF, BOM, `allow-remote = all` (spaces), quoted `"all"`, `ALLOW-REMOTE=…`, `allow_remote=…`, a trailing `[section]`, and explicit `none`: pass. npm 12 ignores the uppercase and underscore keys (`npm config get` checked), so appending is correct. Spaces and quotes count as already set. The CRLF line ending is preserved. On npm 12, a fresh `npm ci` passes for the mirror, spaces and CRLF variants.
