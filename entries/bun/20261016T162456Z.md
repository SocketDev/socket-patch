## False positives ruled out
- A 429 from the upstream registry isn't retried during rollback / takeover restores. CLI_CONTRACT "Throttling" retries only patch-API JSON calls ("Nothing else is retried"), and a registry that doesn't answer is the documented `hosted_restore_refused` refusal. The pin is left untouched, so it's safe. Added to Known non-bugs.
- Mock fixture: the first 79-pin run left `ms@2.1.2`, `ms@2.1.3`, `debug@4.3.4` and `encodeurl@2.0.0` unpatched. The mock keyed patches by name, so a second version of a name got no patch. Re-keyed by `name@version`, then 79/79 passed.
