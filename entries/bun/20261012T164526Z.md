## Filed
- **#1437**: a bare `scan` / `get` (no `--mode`) on a project that holds both vendored entries and hosted pins classes it as vendored (`mode_from_project_state` ignores hosted pins). It then runs the hosted → vendored takeover on every hosted pin, exiting 0 with no JSON warning. That breaks the contract ("a bare scan/get never converts a project"), and it silently undoes a partial #1039 `--mode hosted` takeover. Reproduced on Bun 1.4.3 text + lockb (partial takeover and per-package `get`), on 1.2.23 text, with a bare `get`, and with npm 10.9 (generic). First bad for this direction is `3bcb267f` (#1317). Its parent converted the other way (vendored → hosted).
