**Method:** same as run 1, with the mock rebuilt (`mkpatch.py` + `mock.py`). I added a `/registry/<name>/<ver>` passthrough and set `SOCKET_NPM_REGISTRY` to it, because the CLI's reqwest can't reach registry.npmjs.org from this sandbox even though curl can. Hosted rollback needs that registry lookup. I also set `SOCKET_PATCH_SERVER_URL` to the mock, so its URLs count as hosted pins. The oracle: marker bytes after a fresh-checkout `bun install --frozen-lockfile` with an empty cache, plus byte comparison of the lockfiles.
