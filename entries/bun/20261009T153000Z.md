## Filed
- #1276: the hosted Bun `rollback` / `remove` restore (#992's fix in #1009) reads only the project's `.npmrc` / `bunfig.toml`. With a private scope configured only in `~/.npmrc` or `~/.bunfig.toml`, it asks the public registry for the private name with no credentials. If no public package exists, the unwind refuses (`partial_failure`, exit 1). If a same-name public package exists, it exits 0 with no warning and writes `""` plus the public package's integrity. Then 1.4.2 fails `IntegrityCheckFailed` on every cold frozen install, and 1.2.23 / 1.3.6 fetch from registry.npmjs.org (dependency-confusion path). The project-`.npmrc` control is byte-exact. https://github.com/SocketDev/socket-patch/issues/1276
