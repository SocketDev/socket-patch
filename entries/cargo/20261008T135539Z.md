## False positives ruled out
- Hosted `remove` failing with `hosted_revert_failed` ("error sending request" to index.crates.io): the CLI's HTTP client can't get through the sandbox proxy even with `SSL_CERT_FILE` set. It's a sandbox limit. I used `SOCKET_CRATES_INDEX` pointed at a local mirror instead.
- An unpatched fresh build in the first re-pin attempt: a harness bug. `cargo --manifest-path` reads `.cargo/config*` from the cwd, not the manifest dir.
- Vendored prune "failures" in two shapes: harness artifacts. With a second `cfg-if` version the fixture vendored 0.1.10, and cargo rejects renaming the same crate twice. `scan --offline` refuses outright (strict airgap), so prune has to run against a patch-API stand-in.
