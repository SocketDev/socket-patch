That's the same class as the run-30 non-bug and the #401 resolution, so it's recorded under Known non-bugs.

The refusal is right: pnpm 10 honours the member's `pnpm.overrides` only for an install run from the member, and a root `--frozen-lockfile` install fails `ERR_PNPM_LOCKFILE_CONFIG_MISMATCH`.
