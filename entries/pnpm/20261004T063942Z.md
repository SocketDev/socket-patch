### False positives ruled out
- Hosted standalone `vex` attesting an optional dependency that isn't installed on this OS (`fsevents`): documented manifest-less attestation from the lock pin.
- Rollback leaving `trustLockfile: true` in a user's existing `pnpm-workspace.yaml`: documented (`pnpm_trust_lockfile_left`).
- `ERR_PNPM_NO_OFFLINE_TARBALL` on the first `--offline` install after a hosted pin: the store never fetched the hosted tarball, so it's a fixture artifact. Use an online fresh store.
