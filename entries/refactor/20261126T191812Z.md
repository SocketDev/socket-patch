### Lessons
- **The bench is a patch API for every package manager.** `cargo build -p socket-patch-bench` (25 seconds after the CLI), then:

  ```
  socket-patch-bench serve maven/hosted --bin target/debug/socket-patch --scale 0.02 --work-dir <dir>
  ```

  It writes a small project and a home directory under `<dir>/maven-hosted/work/`, starts the API, proxy and artifact hosts on local ports, prints one `env -i … socket-patch scan --json --cwd <project>` line, and serves until killed. `socket-patch-bench list` names the 43 scenarios; the 20 `<pm>/hosted` ones are npm, pnpm, yarn-classic, yarn-berry, bun, vlt, pip, uv, pylock, poetry, pipenv, pdm, hatch, bundler, composer, cargo, golang, nuget, maven and gradle. Hosted mode is the default with the token the line sets. All 20 servers ran at once.
- **The runner** is 40 lines of Python: split the printed line with `shlex` into the environment, the binary and the project; copy the project to a sibling directory (`work/p-<name>`, so `HOME` and `GIT_CEILING_DIRECTORIES` still fit); change the copy; run `[binary] + args + ['--cwd', copy]` with that environment. For a plant in a user-level file, copy `work/home` too and rewrite every variable that starts with its path. A matrix is a list of functions that edit the copy and may return extra environment variables, times a list of commands.
- **Two plants that need no knowledge of a file format:** replace every `https://` in the project's text files with `https://bot:<token>@`, and replace every `https://<host>` with `https://bot:<token>@repo.corp.example/<host>`. They found the `uv.lock` and `pylock.toml` site.
- **What the harness cannot do.** Its proxy variables point at a closed port, so an undo that asks an upstream registry fails (useful: the failure message is where URLs are quoted). It serves no vendored artifact, so `scan --mode vendored` stops at the download. Its installed copies are synthetic, so `vex` omits them as `hash_mismatch`.
- A wet hosted scan of the vlt project removes the installed copy of the patched package and `node_modules/.vlt-lock.json`. That is the heal the contract describes, not a stray delete.
