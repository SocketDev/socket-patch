### Lessons
- **Signal the binary at random moments in a loop.** Forty lines of Python: copy the tree, start the command, sleep a random part of an unkilled run's time, send the signal, classify the tree by which of the files that would change have changed and by what else appeared. A few hundred runs take minutes and found both the stages and L70. A debug build also stops at the names `SOCKET_PATCH_FAILPOINT` lists (core `utils/failpoint.rs`), but the hosted scan and rollback write through paths that hit none.
- **Then give each torn tree to every command.** The same command again, the opposite one, `list`, `vex`, and the package manager. "The next run finishes it" is the claim to test; what `rollback` says over a tree it cannot see is where L70 was.
- **A subset is not a crash.** The first table of torn hosted states had five that never converge. All five put a later file of the write order ahead of an earlier one. Read the order (a `BTreeMap` of paths) before calling a state reachable.
- **Know which clock a sweep reads.** The stages beside patched files age by ctime, which `touch` resets to now, so my first check called a working sweep broken. I read the function, kept four killed trees and came back after ten minutes. The sweep of `.socket/` reads mtime, and there `touch -d '2 hours ago'` is a fair test.
- **Read the contract before weighing a crash finding.** Line 2075 names the hosted restore's missing journal as a limit. That turned L70 from an issue into a note in ten seconds; I found the line after the kills, and should have looked first.
- **The mode sweep costs two minutes and settles a rule for 21 package managers**: `chown -R 1000`, `chmod 0640`, run as root, compare `lstat` before and after. Root is what makes the owner half testable here.
- The hunt took about 50 minutes of wall time: the builds 4, modes and owners 4, the hosted crash states 9, the agent kills 22 (most of it the loops themselves), the signals and the token 6, the rest reading.
- The register was at 11,991 characters and is at 11,980. L69 joined the collapsed `filed` row, L70 the out-of-charter row, and one note names the kill loop. To make room the two Areas rows are one, the `filed` row's Where cell names no modules, and eight phrases are shorter.
