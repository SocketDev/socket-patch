### Lessons
- An agent-mode fixture needs no server. This script writes one: a project with `left-pad@1.3.0` installed, a manifest record for a two-file patch, and both blobs of each file.

```python
#!/usr/bin/env python3
"""mkagent.py <root>: an npm agent-mode fixture with a two-file patch."""
import hashlib, json, os, shutil, sys
root = sys.argv[1]
def gh(b): return hashlib.sha256(b"blob %d\0" % len(b) + b).hexdigest()
shutil.rmtree(root, ignore_errors=True)
pk = os.path.join(root, "node_modules", "left-pad")
os.makedirs(os.path.join(pk, "lib")); os.makedirs(os.path.join(root, ".socket", "blobs"))
before = {"index.js": b"module.exports = 1\n", "lib/util.js": b"exports.u = 1\n"}
after = {"index.js": b"module.exports = 2\n", "lib/util.js": b"exports.u = 2\n"}
open(os.path.join(root, "package.json"), "w").write(
    '{"name":"p","version":"1.0.0","dependencies":{"left-pad":"1.3.0"}}\n')
open(os.path.join(pk, "package.json"), "w").write('{"name":"left-pad","version":"1.3.0"}\n')
files = {}
for rel in before:
    open(os.path.join(pk, rel), "wb").write(before[rel])
    files["package/" + rel] = {"beforeHash": gh(before[rel]), "afterHash": gh(after[rel])}
    for b in (before[rel], after[rel]):
        open(os.path.join(root, ".socket", "blobs", gh(b)), "wb").write(b)
record = {"uuid": "11111111-2222-4333-8444-555555555555", "exportedAt": "2026-01-01T00:00:00Z",
    "files": files, "description": "d", "license": "MIT", "tier": "free",
    "vulnerabilities": {"GHSA-aaaa-bbbb-cccc": {"cves": ["CVE-2026-0001"], "summary": "s",
        "severity": "high", "description": "d"}}}
json.dump({"patches": {"pkg:npm/left-pad@1.3.0": record}},
    open(os.path.join(root, ".socket", "manifest.json"), "w"), indent=2)
```

- The matrix runner is a loop over `itertools.product("BAXM", repeat=2)`: rebuild the fixture, put each file in its state (before, after, edited, missing), run one command with `--json`, then read back each file's state and run `apply --check` and `vex --output`. Sixteen states of one command take about a second.
- A local stand-in for the authenticated API is the proxy stand-in on another path: `POST /v0/orgs/<slug>/patches/batch` answers `{"packages": [], "canAccessPaidPatches": true}`, with `SOCKET_API_URL`, `SOCKET_API_TOKEN` and `SOCKET_ORG_SLUG` set. Its error shape is `{"error": {"message": …}}`.
