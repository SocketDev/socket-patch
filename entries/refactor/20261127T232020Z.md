### Lessons
- **A guard that looks for an id: change the id.** The guard's unit test and the contract's example both use the patch the run is granted. The earlier patch of the same release is the next state of the same project. For any check of the form "is this one already here", run it with its sibling.
- **When a review fix changed one reader of a rule, grep for the other.** `git log -S mirror_base_depth` showed the fix; `grep -n 'GO_SERVE_ROOT\|SERVE_ROOTS'` in the same file showed `hosted_base_path` still inferring.
- **The harness's patch server is a `--patch-server-url` origin, not Socket's.** Rewriters that own a pin "on Socket's patch server or on the new one's origin" treat a pin on it as neither. To test a project already pinned on the patch server, rewrite that origin to `https://patch.socket.dev` in the project's files after the first scan.
- **The harness serves no artifact for eight package managers** (npm, pnpm, yarn berry, Bun, Bundler, Composer, Maven, Gradle), so a mirror that proxies it answers 599 and every pin is `redirect_mirror_unavailable`. The run sends the mirror only `HEAD` requests: a server that answers 200 to each is a mirror.

```python
# mirror stand-in: python3 any200.py <port> <log>; modes.py answers by the first path segment (/c404/…, /redir/…)
class H(BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"
    def any(self):
        logf.write(f"{self.command} {self.path} AUTH={self.headers.get('Authorization')}\n"); logf.flush()
        self.send_response(200); self.send_header("Content-Length", "0"); self.end_headers()
    do_GET = any; do_HEAD = any
```

- **A pin on a host the run was not given** is the first scan's pin with its origin replaced by `https://repo.corp.example/artifactory/socket-patch`; for an earlier patch, replace the segment before the file name with another canonical uuid. Count the URLs on each host before and after.
- **A failing write needs no mount and no chmod.** As root, a file-size limit with the signal ignored makes every write past N bytes fail with `EFBIG`:

```python
def pre():
    signal.signal(signal.SIGXFSZ, signal.SIG_IGN)
    resource.setrlimit(resource.RLIMIT_FSIZE, (N, N))
subprocess.run([cli, *args], preexec_fn=pre, …)
```

  Scan once without the limit, take the size of each file the run wrote, and run again from a fresh copy with N one byte under each size. It fails the staged write, not the rename.
- `open(p, "w").write(open(p).read().replace(…))` truncates the file before it reads it. One fixture came out empty that way; read first.
