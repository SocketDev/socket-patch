### Lessons
- **Put conflict markers in every file a command reads by its lines.** A reader that ends a section at the first column-0 line reads a conflicted file as a short one, and a conflicted lock is what a merge leaves in every project sooner or later. `git merge-file -p ours base theirs` makes the markers; put them in each section in turn, since only one placement showed the defect.
- **A guard that says "a file I cannot read keeps everything" is as good as the parser's idea of unreadable.** The existing test fed it one unreadable lock, mixed line endings. Ask what else makes the file unreadable to a person, and feed the guard each.
- **Run a cleanup with and without `--json`.** The two paths split before the hosted rewrite, so one tidied and the other returned early. Compare the files afterwards, not the output.
- **Read `docs/design/` before filing a drift.** `lock-model-divergences.md` lists about fifty places where the lock readers and the modes disagree, each with the owner's decision. My first lead of the run was its row N7.
- **For a timing test, work out what the unguarded code would measure.** A bound of a third of a phase over three equal units is the unguarded wait. One unit makes the same bound mean something.
- **Golden fixtures are projects.** `project/` and `expected/` of a case under `tests/fixtures/pnpm-registry-overrides/` are a routed project that real pnpm wrote, on a host a flag can name (`--patch-server-url https://patch.test`). Every state of the route is that project with one file put back or edited, and `repair` needs no patch API for it.
- **The addon builds in two minutes and rebuilds in two seconds.** `SOCKET_PATCH_NODE_CARGO_PROFILE=dev node crates/socket-patch-node/npm/scripts/build-addon.mjs`, then `require('<repo>/crates/socket-patch-node/npm/index.js')` from any script. A mutant behind `std::env::var("SPMUT")` in the addon crate costs one rebuild of that crate alone. Delete `npm/socket_patch_node.node` afterwards.
- **My harness was wrong once.** It joined two request logs and took the lines past the old length, which gave stale lines once both logs grew. Count each log by itself.
- The hunt took 38 minutes of wall time: the addon and its mutants about 20, the environment 5, the route 13. The conflict was the forty-third state of the route.
