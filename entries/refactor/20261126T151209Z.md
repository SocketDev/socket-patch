### Lessons
- Running the command a lead is about under a broken environment found more than reading it. A script named after a tool, first on `PATH`, is a failing probe (`exit 1`) or a hanging one (`exec sleep 600`); a line appended to a log shows which probes a command makes. `rollback` was the only command of seven that probed anything.
- A patched global copy needs no npm: `<dir>/lib/node_modules/left-pad/` with the patched files, and an `npm` script that prints `<dir>/lib/node_modules` for `root -g`. With the agent fixture of the 12:55Z entry as the project, `rollback` then `rollback -g` is the whole test.
- A closed pipe is `r, w = os.pipe(); os.close(r)` with `w` passed as the child's stdout or stderr.
- The entrypoint mode's global pass scans this machine's real global packages. Always give it `--proxy-url` pointing at a local stand-in, never the real API, or it patches the sandbox.
- A stand-in for the public proxy that offers one patch is 50 lines: `POST /patch/batch` answers `packages[].patches[]` (`uuid`, `purl`, `tier`, `cveIds`, `ghsaIds`, `severity`, `title`), `GET /patch/by-package/<purl>` the search shape, and `GET /patch/view/<uuid>` the patch with base64 `blobContent` and `beforeBlobContent`.
- This sandbox refuses to execute a binary downloaded during the run. Leads that need scala-cli, like those that need Go, .NET or Docker, cannot be settled here.
