- `build.target-dir` in an included file: the crate is patched, its fingerprints in that directory stay, the next `cargo build` compiles nothing and the binary keeps the pre-patch code. No `cargo_build_cache_stale` warning.
- a `paths` override in an included file: the gate does not protect the crate, the scan patches the registry copy and `vex` attests it, while cargo builds the override.
- hosted mode, over the bench's Cargo project with a `vendor/` directory: the direct layout is refused with `redirect_cargo_directory_source`, the included one is pinned.

The cause is three readers of cargo's config that do not know the key: `config_layer_paths` (core `formats/cargo/source_replacement.rs`, line 114; its callers are the crawler and the build-directory lookup), the hosted rewriter's single project layer (core `patch/redirect/mod.rs`, line 2163) and the gate's `cargo` (core `patch/user_patches.rs`, line 1113). Three unit tests fail on `main`; the issue has them, the evidence for each site and what cargo 1.97.0 does with `include` (precedence, relative paths, nesting, optional files), measured with `cargo metadata`.

**New: L47, filed as #2306.** A `[replace]` key is a package ID specification. Cargo 1.97.0 builds the replacement under `"fnv:1.0.7"`, `"fnv@1.0.7"`, `"https://github.com/rust-lang/crates.io-index#fnv@1.0.7"`, `"registry+https://github.com/rust-lang/crates.io-index#fnv:1.0.7"` and the same with `@`, which is what `cargo pkgid fnv` prints. ### Lessons
- **Ask the package manager what it reads, then ask socket-patch.** `cargo metadata` names the manifest of every package cargo builds. One line of it against the path the scan patched is the whole test, and it works for any layout a config can express. Other tools have such a command too (`bundle list --paths`, `uv pip show -f`); I did not run them.
- **A toolchain newer than the repository's pin shows what users have.** This repository builds with cargo 1.93.1, where `include` is ignored, so no suite here could have seen #2305. Outside the repository directory the sandbox's `cargo` is 1.97.0 (`cargo +stable` inside it).
- **A key the real tool takes in several spellings is a list to run in full.** The gate's one `[replace]` test uses the colon spelling. Build the project with the real tool for each spelling first: cargo rejected three of the eight I wrote, and those are not real inputs.
- **Real cargo runs offline here.** `~/.cargo/registry` holds 218 crates. A copy of its `index/`, one `.crate` and one `src` directory make a `CARGO_HOME` of its own:

```python

W = os.path.abspath(sys.argv[1]); home = os.path.expanduser("~/.cargo/registry"); idx = os.listdir(home + "/index")[0]
def gh(b): return hashlib.sha256(b"blob %d\0" % len(b) + b).hexdigest()
shutil.rmtree(W, ignore_errors=True)
os.makedirs(f"{W}/cargo/registry/cache/{idx}"); os.makedirs(f"{W}/cargo/registry/src/{idx}"); os.makedirs(f"{W}/home")
shutil.copytree(f"{home}/index", f"{W}/cargo/registry/index", symlinks=True)
shutil.copy(f"{home}/cache/{idx}/fnv-1.0.7.crate", f"{W}/cargo/registry/cache/{idx}/")
shutil.copytree(f"{home}/src/{idx}/fnv-1.0.7", f"{W}/cargo/registry/src/{idx}/fnv-1.0.7")
app = f"{W}/app"; os.makedirs(app + "/src"); os.makedirs(app + "/.git"); open(app + "/.git/HEAD", "w").write("ref: refs/heads/main\n")
open(app + "/Cargo.toml", "w").write('[package]\nname = "app"\nversion = "0.1.0"\nedition = "2021"\n\n[dependencies]\nfnv = "=1.0.7"\n')
open(app + "/src/main.rs", "w").write('use std::hash::Hasher;\nfn main() {\n    let h = fnv::FnvHasher::default();\n    println!("{:x}", h.finish());\n}\n')
before = open(f"{W}/cargo/registry/src/{idx}/fnv-1.0.7/lib.rs", "rb").read()
after = before.replace(b"FnvHasher(0xcbf29ce484222325)", b"FnvHasher(0x1111111111111111)")
purl = "pkg:cargo/fnv@1.0.7"
json.dump({purl: [{"uuid": "cccccccc-0000-4000-8000-000000000001", "purl": purl, "tier": "free", "severity": "high", "ghsa": "GHSA-cccc-cccc-0001", "cve": "CVE-2026-0001", "publishedAt": "2026-01-01T00:00:00Z",
    "files": {"lib.rs": {"before": base64.b64encode(before).decode(), "after": base64.b64encode(after).decode(), "beforeHash": gh(before), "afterHash": gh(after)}}}]}, open(f"{W}/catalog.json", "w"))
```
