### Lessons
- **Take a command's writes apart.** A hosted scan writes two to five files, and a merge, a `git checkout` of one file or a hand edit leaves any subset of them. One loop builds each subset over the pre-scan tree and runs the next scan, `vex` and `scan --vex` on it; 56 states took a minute. The rows that neither converge nor report a skip are the defects. The same loop fits `vendor`, `rollback` and `remove`.
- **When a warning says "skipped" and the summary says "patched", believe neither: run the package manager.** Bundler 2.6.2 settled it in one command (`BUNDLE_FROZEN=true bundle install` fails before any fetch). Outside the bench's environment this sandbox reaches rubygems.org.
- **A comment that says "X must never confirm by substring" marks a list to complete.** `confirm` has that sentence for Cargo, Go, yarn berry, pdm and Gradle, each with a fix behind it. The ecosystems left on the substring arm are the ones to run.
- **The disk-against-memory runner** (`socket-patch-bench serve <pm>/hosted` must be running; `<pm>.out` is its output):

```python
import base64, json, os, shlex, shutil, subprocess
SKIP = {"node_modules", ".venv", "vendor", ".git", "target", ".bundle"}
def parse(out):                       # the line `serve` prints -> env, binary, project
    parts = shlex.split([l for l in open(out) if l.startswith("env -i")][0]); env, i = {}, 2
    while "=" in parts[i] and not parts[i].startswith("/"):
        k, v = parts[i].split("=", 1); env[k] = v; i += 1
    return env, parts[i], parts[-1]
def tree(root):
    out = {}
    for d, dirs, files in os.walk(root):
        dirs[:] = [x for x in dirs if x not in SKIP]
        for f in files:
            p = os.path.join(d, f)
            if not os.path.islink(p): out[os.path.relpath(p, root)] = open(p, "rb").read()
    return out
def run_pair(env, binary, work, files, label):
    disk = os.path.join(work, "p-" + label); shutil.rmtree(disk, ignore_errors=True)
    for rel, data in files.items():
        p = os.path.join(disk, rel); os.makedirs(os.path.dirname(p), exist_ok=True); open(p, "wb").write(data)
    os.makedirs(disk + "/.git", exist_ok=True); open(disk + "/.git/HEAD", "w").write("ref: refs/heads/main\n")
    r = subprocess.run([binary, "scan", "--mode", "hosted", "--json", "--cwd", disk], env=env, capture_output=True, text=True, cwd=work)
    after = tree(disk); changed = {k: v for k, v in after.items() if files.get(k) != v}
    text, binary = {}, {}
    for k, v in files.items():
        try: text[k] = v.decode("utf-8")
        except UnicodeDecodeError: binary[k] = base64.b64encode(v).decode()
    m = subprocess.run([binary, "hosted-bundle", "--api-url", env["SOCKET_API_URL"], "--api-token", env["SOCKET_API_TOKEN"],
                        "--org", env["SOCKET_ORG_SLUG"]], env=env, input=json.dumps({"files": text, "binaryFiles": binary}), capture_output=True, text=True, cwd=work)
    mj = json.loads(m.stdout); mem = {f["path"]: f["content"].encode() for f in mj["changedFiles"]}
    return json.loads(r.stdout), changed, after, mj, mem      # compare `changed` with `mem`
```

The engine result's `projects[].redirect.patches[].action` is `pinned` or `unpinned`; the disk run's `events[]` are `applied` or `skipped`.
