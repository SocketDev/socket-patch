### Lessons
- For a test that cannot fail, mutate production, not the test's arguments: the diff is two lines, anyone can re-apply it, and the same diff then shows the fixed test red. Then drop the flag from one call at a time, to show each assertion holds without the others.
- A control that reads something the test does not own (here the account's Gradle cache) needs three things said out loud: that it only reads, that it asserts nothing about the contents, and what a failure prints.
- The harness defaults that keep tests hermetic are also what hides a flag. `isolate_cli` pins `GRADLE_USER_HOME`, and three tests asserted things that pin decides. Other flags that name a cache or a root (`--global-prefix` for the other ecosystems, `MAVEN_REPO_LOCAL`) are worth the same mutation.
