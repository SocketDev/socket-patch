### Lessons
- Reading for "which message quotes a URL" found hundreds of candidates and nothing. Planting one token in every place a package manager writes a URL, running every mode, and grepping the output for it took ten minutes and found four sites. The runner is a loop: copy the project, run one command, count the output lines that hold the token.
- The 17 projects are files only. npm family: a `package.json` and a lock whose entry for `left-pad` is `git+https://x-access-token:ghp_<token>@github.com/acme/left-pad.git` (the `yarn.lock` block key and `resolved`; the `pnpm-lock.yaml` importer, package key and `resolution.repo`; the `bun.lock` package tuple), plus `node_modules/left-pad`. Cargo: a `Cargo.lock` whose `cfg-if` has `source = "git+https://…"`, `"registry+https://bot:<token>@host/index"` or `"sparse+https://…"`. PyPI: a `requirements.txt` with `--index-url`, `--extra-index-url`, `--find-links` or `six @ https://bot:<token>@host/…whl`; a `Pipfile.lock` source; a `uv.lock` registry; a `poetry.lock` `[package.source]`. Gem: a `GIT` remote, and a `GEM` remote. Composer: `source.url` and `dist.url`.
- The stand-in for the patch API grew one route, so one server serves all three modes: `POST …/patch/package` (and `/v0/orgs/<org>/patches/package`) answers `{"results": {"<uuid>": {"status": "granted", "url", "purl", "artifacts": [{"kind": "tarball", "url", "integrity": {"sha512", "sha1"}}], "registryOverride": null}}}`. It also logs every request body, which shows what a scan sends: that settled #595 in one run per ecosystem.
- An API token of the real shape is `sktsec_` followed by 44 characters and `_api`.
- A hand-built venv needs `include-system-site-packages = false` in `pyvenv.cfg`. Without the key the crawler reads the venv as CPython does, with the system packages included, and the scan sent 26 packages of this machine.
- With telemetry on, a run posts to `<proxy-url>/patch/telemetry`, so the same stand-in shows what telemetry carries.
- `git fetch --deepen=2500 origin main` and `git log -i --grep=redact` found #1026 in one command. An earlier fix of the same class is the fastest way to see which sites it left out.
