### Lessons
- **Count what the entries never name.** A loop over the flags of every `--help` and over the CLI's modules, each grepped in `entries/refactor/`, listed 27 flags and nine modules no entry mentions. The matcher was one of them, and the first batch of commands over it showed the defect. Most of the others turned out to be exercised under another name, so the list is a place to look, not a finding.
- **Give a path argument every spelling a script would.** Relative, `.`, `./`, `"$PWD"` and `"$PWD/sub"`, with no `--cwd`. The suites pin an absolute `--cwd` for hermeticity (the register's note on `--cwd` already says why), and the matcher's unit tests bind `/proj`, so neither can meet a relative candidate with an absolute pattern.
- **Two comments in one file that contradict each other mark the spot.** Line 130 says crawler paths are not absolute and line 145 says they are.
- **When one argument is read by two implementations, run both.** `[PATHS]` is a project directory in hosted and vendored mode and a glob over installed copies in agent mode. The first accepts every spelling, which is what makes the second's answer a defect and not a design.
- **A catalog from the installed bytes.** `mkcat.py <out> <purl>=<package dir>:<file>` reads each installed file as the patch's `before` and appends a comment for `after`; the stand-in API of the 22:56Z entry of 11-26 serves it unchanged. With a real `npm install` that is an agent-mode project and patch service in under a minute:

```python
#!/usr/bin/env python3
"""mkcat.py <out catalog.json> <purl>=<installed package dir>:<file>[,...] ..."""
import sys, json, base64, hashlib, os
def gh(b): return hashlib.sha256(b"blob %d\0" % len(b) + b).hexdigest()
cat = {}
for n, spec in enumerate(sys.argv[2:], 1):
    purl, rest = spec.split("=", 1)
    d, files = rest.split(":", 1)
    fs = {}
    for f in files.split(","):
        before = open(os.path.join(d, f), "rb").read()
        after = before + b"\n/* socket patched %d */\n" % n
        fs["package/" + f] = {"before": base64.b64encode(before).decode(), "after": base64.b64encode(after).decode(), "beforeHash": gh(before), "afterHash": gh(after)}
    cat[purl] = [{"uuid": "%08x-1111-4111-8111-%012x" % (n, n), "purl": purl, "tier": "free", "severity": "high", "ghsa": "GHSA-aaaa-bbbb-%04d" % n, "cve": "CVE-2026-%04d" % n, "publishedAt": "2026-01-01T00:00:00Z", "files": fs}]
json.dump(cat, open(sys.argv[1], "w"), indent=1)
```
