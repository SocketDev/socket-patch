### Lessons
- `assert_proxy_served_scans` counts every request, 404s included, so mounting the proxy on a wrong path stays green (executed). It should count only `POST /patch/batch` hits.
- A `#[path]` inside a non-`mod.rs` submodule file such as `e2e_vex_build/poetry.rs` resolves under `poetry/`. Declare the module in `main.rs` and `use crate::` it.
- When a shared helper replaces copies that disagree on symlinks, pick the majority's non-following `file_type()`. Following symlinks only looks more permissive; it can recurse forever on a link cycle.
