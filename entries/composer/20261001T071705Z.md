## Cells (global mode)

- `scan -g` report-only, default home: pass on Linux (1.10–2.10) and macOS (1.10/2.2/2.10). **Fail on Windows (all 3 versions) → #438**: `%APPDATA%\Composer` is never found. `composer.bat` isn't spawned (`Command::new` without `resolve_tool`), and the fallback doesn't list APPDATA.
- `scan -g --mode hosted` / `--global-prefix … --mode hosted`: pass on every OS and version (exit 2, nothing written).
- `scan -g --mode agent` → global file patched; `vex -g` attests 1; `rollback -g` restores byte for byte: pass on Linux and macOS, and on Windows with an explicit `COMPOSER_HOME`. Fail on Windows with the default home (#438).
- `vex -g` after `composer global reinstall` (pristine bytes): it omits with `not_applied`, which is correct. `apply -g` then re-patches. Pass (Linux, 2.8.12).
- `-g` from inside a Composer project touches only the global copy, and a scan without `-g` touches only the project copy: pass (Linux, 2.8.12).
- `scan -g` with composer not on PATH (phar) and `XDG_CONFIG_HOME` set: **fail**, folded into #438.
- Custom global `vendor-dir` (`composer global config vendor-dir deps`, or `COMPOSER_VENDOR_DIR`): **fail on all 3 OS × all versions → #439.** `--global-prefix <home>/deps` works around it.
- Local agent scan with a user-level `composer config -g vendor-dir lib` (`$COMPOSER_HOME/config.json`): **fail → #439** (Linux, 2.8.12, twice).
- Regression check: both #438's fallback gap and #439 behave identically on the v4.0.0 binary, so neither is a v5 regression.

## False positives ruled out

- The first `rollback -g` failure ("Before blob could not be downloaded") came from my mock missing `beforeBlobContent` and the blob route. With both present, it passes.
- Agent mode under `-g` writes `.socket/manifest.json` in the cwd, so `rollback -g` must run from the same directory. That's per-cwd manifest design, not a bug.
- The ubuntu "composer not on PATH" pass was invalid: stripping `/usr/bin` also removed bash. The local Linux run, which removed only `/usr/local/bin`, is valid and passes (the `~/.config/composer` fallback).
