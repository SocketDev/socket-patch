## Cells (all on `61cfb9b`, Linux)

- Hosted psr/log → `composer require psr/container:2.0.2 --no-install` (partial update of a *different* package): the rewritten psr/log entry is kept on 2.2.30 and 2.10.3. **pass**. Composer 1.10.28 can't resolve new packagist packages any more (packagist's Composer 1 metadata is frozen), so it was tested on an inline-repo fixture instead (next bullet).
- Hosted inline-repo `acme/tool` → `composer require acme/other:1.0.0` → install: 2.2.30 and 2.10.3 keep the rewrite and install patched (**pass**). **1.10.28 re-resolves acme/tool from composer.json's inline repository, restores the upstream `file://` dist, drops the shasum and installs unpatched.** That's Composer 1 partial-update behaviour, not a socket-patch defect, and it's limited to Composer 1 + custom repos. Not filed. docs/testing/composer-compatibility.md "What undoes the wiring" doesn't list `composer require <other>` on Composer 1. Candidate docs gap; see Backlog.
- Hosted psr/log → `install --prefer-source`, `reinstall psr/log --prefer-source`, `config preferred-install source` + fresh install (2.2.30, 2.10.3): source is dropped, so the patched dist installs every time. **pass**.
- Exec bits: upstream vs hosted vs vendored install of a package with `bin/tool` (listed bin) and `tools/helper.sh` (non-bin, 0755), on 1.10.28 / 2.2.30 / 2.10.3. Both stay `rwxr-xr-x` in every mode, the patch is applied, and `.socket/vendor` keeps the 0755 too. **pass** ×9.
- `composer-plugin` package, hosted and vendored, with `allow-plugins`, on 1.10.28 / 2.2.30 / 2.10.3: the plugin activates from the patched bytes ("patched") in both modes, while upstream activates pristine. **pass** ×6. (On 2.10.3 as root you need `COMPOSER_ALLOW_SUPERUSER=1`, or plugins are disabled in every mode.)
- `get <uuid> --mode hosted` over a vendored psr/log entry: **fail #536** (comment added).
- Hosted `rollback` of an inline-repo entry: refused with "restore it from version control" and the lock left rewritten. Documented fail-closed behaviour (same as the hosted → vendored refusal). **pass**.
