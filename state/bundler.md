[agent] Progress ledger for the scheduled Bundler (RubyGems) bug-hunt routine (label pm:bundler).

Last run: 2026-11-26, main `cfc870f`, release 5.1.0, newest Bundler 4.1.1. Tested so far: Bundler 1.17.3, 2.3.27 to 2.6.9, 4.0.18 to 4.0.25, 4.1.0, 4.1.1 on Ruby 3.1.6, 3.2.6, 3.3.6.

Harness notes: rubygems.org is reachable, the Socket patch API is not. Use the repo's stand-in, `tests/nokogiri/patch_service.rb`: `PatchService.new(name, version, platforms, uuid, ghsa, workdir, mark)` appends `mark` to `lib/<name>.rb` of the real gems and serves the patches API, the index and the artifacts for ONE gem on a loopback port (org `nokogiri-e2e`). An empty platform list gives a ruby-platform patch; vendored mode then also needs a `gem-stub-gemspec` artifact (add it to `package_result` and serve the gem's `spec.to_ruby`). For several gems, a superseding patch or agent mode, put one loopback server in front of several instances (subclass it, override `url` with the front's): route a path that holds a uuid to that instance's `respond`, merge `batch` (by the body's `components`) and `package` (by `uuids`), answer `by-package/<purl>`, and serve `/v0/orgs/<org>/patches/blob/<git-sha256>` from `@before` / `@after`. Behind a path prefix it is a patch mirror too (`--patch-mirror-url`). Pass `--api-url <mock> --patch-server-url <mock> --api-token fake --org nokogiri-e2e` to every command. Rubies are in `/opt/rbenv/versions` (3.1.6: Bundler 2.3.27, 2.6.9; 3.2.6: 2.4.19, 4.0.18; 3.3.6: 2.5.22, 4.0.18); `gem install bundler -v <v>` works. Select a Bundler with `BUNDLER_VERSION`. A realistic project: `gem install rails -v 8.0.2` into a scratch `GEM_HOME`, then `rails new app --skip-git --skip-bundle --skip-javascript --skip-hotwire --skip-docker`. A private mirror: `gem generate_index` plus `python3 -m http.server` (its index has base64 checksums, #2285). A release build takes 9 minutes; `gem install bundler -v <v>` each run for anything newer than the list above. `vex` writes with `--output`; `remove` takes one purl. No Ruby 3.4 / 4.0 here. Downloaded scanners (Grype, Syft, Trivy) may not be run in the sandbox.
