[agent] Progress ledger for the scheduled Bundler (RubyGems) bug-hunt routine (label pm:bundler).

Last run: 2026-11-25, main `e685fb1`, release 5.1.0, newest Bundler 4.1.0. Tested so far: Bundler 1.17.3, 2.3.27 to 2.6.9, 4.0.18, 4.0.24, 4.1.0 on Ruby 3.1.6, 3.2.6, 3.3.6.

Harness notes: the sandbox reaches rubygems.org but not the Socket patch API. Use the repo's own stand-in, `tests/nokogiri/patch_service.rb`: `PatchService.new(name, version, platforms, uuid, ghsa, workdir, mark)` appends `mark` to `lib/<name>.rb` of the real gems and serves the patches API, the index and the artifacts for ONE gem on a loopback port (org `nokogiri-e2e`). An empty platform list gives a ruby-platform patch; vendored mode then also needs a `gem-stub-gemspec` artifact (add it to `package_result` and serve the gem's `spec.to_ruby`). For several gems, a superseding patch or agent mode, put one loopback server in front of several instances: override each `url` with the front's, route a path that holds a uuid to that instance's `respond`, merge `batch` (by the body's `components`) and `package` (by `uuids`), and serve `/v0/orgs/<org>/patches/blob/<git-sha256>` from `@before` / `@after`. With a path prefix stripped it is a patch mirror too (`--patch-mirror-url http://localhost:<port>/<prefix>`). Pass `--api-url <mock> --patch-server-url <mock> --api-token fake --org nokogiri-e2e` to every command. Rubies are in `/opt/rbenv/versions` (3.1.6: Bundler 2.3.27, 2.6.9; 3.2.6: 2.4.19, 4.0.18; 3.3.6: 2.5.22, 4.0.18, 4.1.0); `gem install bundler -v <v>` works. Select a Bundler with `BUNDLER_VERSION` (a lock's `BUNDLED WITH` can win). A realistic project: `gem install rails -v 8.0.2` into a scratch `GEM_HOME`, then `rails new app --skip-git --skip-bundle --skip-javascript --skip-hotwire --skip-docker`. A private mirror: `gem generate_index` plus `python3 -m http.server` (no webrick here). A release build takes 15 minutes. `vex` writes with `--output`; `remove` takes one purl. No Ruby 3.4 / 4.0 here.

- "the patched gem's gemspec differs from the installed one" after a hosted scan: a mock gem rebuilt with `gem build`. Repack with the original `metadata.gz`.
- `vex` / `list` report no patches on a hosted project whose patch URLs are on loopback: pass `--patch-server-url`.
- `vex` exits 2 asking for a product when the project has no git origin or gemspec: pass `--product`.
- Hosted `rollback` refusing "not rubygems.org" when the upstream is the mock: a harness artifact (a real mirror is #2230).
